# autoPGDiff 完整实验记录

## 项目概述

**PGDiff** 是一篇 NeurIPS 2023 论文的方案，用于**人脸修复**：给定一张模糊/退化的人脸，用扩散模型（DDPM）生成高清输出。核心思想是让 restorer（一个预训练修复网络）在每个扩散去噪步提供"引导梯度"，把生成方向拉向清晰人脸。

**本项目**在 PGDiff 基础上搭建了自动化实验框架，系统性探索了 41 个独立方向，目标是找到在质量、速度、显存三个维度上的最优配置。

## 核心术语

| 术语 | 全称 | 含义 |
|------|------|------|
| **PSNR** | Peak Signal-to-Noise Ratio | 与 GT 的像素级相似度，越高越好。但**不反映感知质量** |
| **SSIM_gt** | Structural Similarity (vs GT) | 与 GT 的结构相似度，越高越好 |
| **NIQE** | Natural Image Quality Evaluator | 无参考自然度评分，**越低越自然**。是感知质量的核心指标 |
| **LQ / GT** | Low Quality / Ground Truth | 退化输入 / 高清真值。测试对保存在 `testdata/pairs/` |
| **RC** | Restorer Calls | 每张图的 restorer 调用次数。决定了推理速度 |
| **K** | Guidance Every K | 每 K 个扩散步执行一次引导。K=1 是每步都引导（论文原配） |
| **s_end** | Stop fraction | 引导在 t/T < s_end 后停止（早停）。论文原配不使用 |
| **scale** | Guidance scale | 引导梯度的强度系数。论文原配为 0.10 |
| **LINEAR** | Linear schedule | 引导强度从 0.3→1.0 线性衰减（autoresearch 引入） |
| **CONSTANT** | Constant schedule | 引导强度恒为 1.0（论文原配） |
| **BLOCK_UNET** | 梯度阻断 | 将 restorer 移出 autograd 图，VRAM −77%，质量零影响 |
| **RESIDUAL_BLEND** | 残差混合 | output = (1−b)×diffusion + b×LQ_input。b=0.5 大幅提升 PSNR 但破坏自然度 |
| **Huber** | Smooth L1 Loss | β=1.0 时截断大误差惩罚，比 MSE 更鲁棒但 PSNR 更低 |
| **DDPM** | Denoising Diffusion Probabilistic Models | 扩散模型的逐步去噪采样过程 |
| **DPM-Solver** | — | 二阶 ODE 求解器，用 15~500 步近似 DDPM 1000 步 |
| **DDIM** | Denoising Diffusion Implicit Models | 确定性采样变体，100 步可达 DDPM 1000 步效果 |
| **V2** | — | 早期使用的自定义指标（SSIM_to_LQ × naturalness × sharpness_gain），后证实有系统性缺陷，全部弃用 |

> **统一指标**：PSNR(dB)↑ / SSIM_gt↑ / NIQE↓ / Time(s)↓ / VRAM(MB)↓  
> **测试图像**：Mild: `0000_00010.png` (PSNR_LQ=31.16) / Severe: `0006_00092.png` (PSNR_LQ=22.21)  
> **硬件**：NVIDIA A10 | **默认**：seed=1234, DDPM 1000步, IMAGE_SIZE=512

```

## Phase 3：DPM 崩溃根因调查（12 次提交）

> 为什么 DPM 不行？四个假设逐个排除。

## Phase 10：NIQE 突破

> **过渡**：Phase 8-9 始终把 PSNR 作为第一优化目标，结果 N3(scale=1.0) 拿到了 31.06 dB 的最高 PSNR。
> 但实测原始论文代码时发现：论文输出 PSNR 仅 26.47，**NIQE 却只有 756**（我们的 N3 是 4482）。
> 这意味着 PSNR 高 ≠ 修复质量好——RESIDUAL_BLEND=0.5 把输出混回了模糊输入，PSNR 是虚高的。
> 这一阶段的核心假设：去掉 BLEND 并下调 scale，应能匹配论文的 NIQE 同时保持可接受的 PSNR。 — "PSNR 是假象，BLEND 是毒药"

> **转折点**：实测发现原始论文代码输出 PSNR 仅 26.47、NIQE 却仅 756（极自然）。  
> 我们的"高 PSNR"配置 RESIDUAL_BLEND=0.5 是把输出混回了模糊输入——PSNR 虚高 +3.8 dB，但 NIQE 飙升 6 倍。

> 1. **BLEND 是假象**：RESIDUAL_BLEND=0.5 贡献 +3.82 dB 的 PSNR 但让修复退化成了"输入加权平均"

> 4. **K=2 + scale=0.15 + blend=0 = 真正的 Pareto 最优点**：在轻度退化下自然度持平论文，严重退化下 PSNR 和自然度双超
